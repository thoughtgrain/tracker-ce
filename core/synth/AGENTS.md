# core/synth: the synth host glue (Tracker+ and Tracker Mini)

This adds to the root [AGENTS.md](../../AGENTS.md); it doesn't replace it.

- **Engines aren't compiled in any more.** Every engine is a `.psyn` plugin in `/Synths` on the SD card. `PsynLoader::scanAndRegister` (`synth/source/synths/PsynLoader.cpp`) registers them at boot, and the Model menu is built from `Synth::getSynthTypes()`. The factory engines are prebuilt binaries in `synth/prebuilt`; the open-source ones are built from `synth-plugin-sdk` (`make psyn`). To add one, follow the `synth-engine` recipe ([`docs/recipes/synth-engine.md`](../../docs/recipes/synth-engine.md)).
- **This directory is the host side, and it's `FEATURE_SYNTH` only.** `Synth.cpp`, `MidiAdapter.cpp` and `FileSystemAdapter.cpp` connect `core/` to the PolySynth library, which `synth/makefile` now builds from `synth/source` into `libPolySynth.a`. The Original Tracker compiles none of it, so wrap new files in `#ifdef FEATURE_SYNTH` like `Synth.cpp` does.
- **Plugin voices run in the audio interrupt.** `PolySynth::update` (`core/libs/Audio/synth_PolySynth.cpp`) calls `Synth::renderAudioBuffer` every block, and that ends in each plugin's `voice_render_audio`. The rules for any audio `update()` apply to plugin code: no heap, no SD, no `double`, no UI. `PsynHostApi`'s file and WAV calls are main-loop only.
- **Creating a voice can read the SD card.** `PsynVoiceWrapper`'s constructor calls `ensurePluginLoaded`, which loads an evicted or not-yet-loaded engine from `/Synths` into the plugin arena. Engine changes have to happen in main-loop code, never from a MIDI handler or the sequencer.
- **Engine IDs are stored in projects.** A plugin's ID is its header's `type_id_play_tracker`. If that's 0 (or taken), `PsynLoader` hands out the next free ID from 100, in sorted file-name order, so adding another plugin can shift it and a saved project then opens a different engine. Give every plugin a fixed ID, and append new built-in ones to `InstrumentTypeId` (`synth/include/PolySynth/config.h`) without renumbering.
- **Memory is a fixed 6 MB pool.** `PSYN_RAM_POOL_SIZE` (`core/source/mtStructs.h`) holds the plugin arena (`PsynLoader::kArenaSize`, 1,920 KB, inactive engines evicted when full) and the synth sample pool. It comes out of `SAMPLE_MEMORY_SIZE`, so growing it takes sample memory away from every user.
