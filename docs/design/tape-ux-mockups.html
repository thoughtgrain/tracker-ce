Tape Project Screens

These are the screens a Tracker user already knows, with what a tape project adds to each. There's no new module. The tape is a play mode in Sample Playback, Grain, Ripple and Echo are send effects in Master, modulation is Automation, lanes are extra FX columns, and recording happens in the Sample Recorder. The notes beside each screen say what a tape project adds to it. The written spec is docs/design/tape-ux.md.

File → New Project → type

One of the two new pieces of UI. Spec §2.

fProjEdit.cpp · a list, like the file and Config lists

Press New Project and a list of the four types opens, each with a one-line summary. Turn the encoder or use Up/Down to pick, then press Create.

  • Default is highlighted when the list opens, so Create makes today's 16-track project with one extra press.
  • Create writes C-4 TA on step 1 of pattern 1 for each tape. It's an ordinary note that starts the tape.

Mini: ±1 or Up/Down moves through the list, and button 8 creates.

Pattern editor: lanes are FX columns

Tape 4. Tape A shows its FX3·4 pair; tracks 3 and 4 are ordinary. Spec §5.

fPatternEdit.cpp · Fx pressed again

A tape track has four FX columns where an ordinary track has two. Pressing Fx again swaps the visible pair between FX1·2 and FX3·4, the way Note pressed again swaps in Micro-move and Volume. The header shows which pair is up.

  • They're the same FX list, entry, Fill, Copy and Undo you already use. The new tape FX are new entries in that list.
  • Here, FX3 holds a Fill of Speed from 100 down to −100 over steps 9–14, and FX4 holds a Roll, an existing FX.
  • Ending a stutter works as it does today: write the FX again with 0.
  • The sample strip: a thin waveform beside a track runs down with the steps, showing the stretch of sample each step plays. It appears on any track whose sample keeps playing across steps, in Default projects too, not only on tapes. Solid lines mark a note starting or jumping to a slice; dashed white lines mark a loop wrapping. On Tape A it narrows and goes flat as the Speed fill slows the tape to a stop; on track 4, a looping pad started on step 0 wraps every six steps.

Mini: the same, with the Fx button and ±1/±10.

Sample strips in a Default project

Every project type, not only tapes: a looping break, a synth pad and a one-shot vocal each get a strip, and short drum hits don't. Spec §5.

pattern editor · Config: Sample strips
Loop
Track 2: a break started on step 0, wrapping at its loop end every eight steps (dashed line). It keeps going across the pattern end.
Synth
Track 3: a synth has no stored sample, so its strip is the part's real output, captured as it plays. Rows already heard on this pass are bright; rows ahead are dim, from the last pass. The attack of each note and the release after OFF show as the waveform swelling and fading.
One-shot
Track 4: a vocal starting on step 2. The strip ends where the sample does.
Drums
Track 1: hits shorter than a beat get no strip, so the grid stays clean. All notes in Config shows them too.
Cost
A primitive sketch: four short lines per row, drawn from a 128-byte peak table per sample, or 1 captured byte per quarter-step for synths. It's drawn only on the redraws the pattern editor already makes, and it drops to fewer lines before notes or FX would. Config → Sample strips: Off captures nothing, allocates nothing and draws nothing.

Sample Playback, play mode Tape

Tape A as the instrument, then SamplePlay. The screen you know, with one new play mode. Spec §3.

gSamplePlay.cpp · Play Mode on 7–8
  • Loop Start and Loop End set the window, as in the loop modes. The slice markers are drawn as Slice mode draws them.
  • New in Tape mode: Speed, a bar ruler under the waveform, and on More: Sync (bars), Wow, Flutter, Rotate, Xfade, Slices.
  • A note on a tape step jumps to a slice, and the tape keeps rolling. Reverse, Position, Slice, Tune and Roll are existing FX and work on a tape as named.

From the pattern screen:

  • C-4 TA starts it, and with Sync on it carries across patterns and loops without restarting.
  • Other TA notes jump slices: C-4 is slice 1, D#5 is slice 16. The pads audition and write them.
  • OFF stops it, and the next TA note brings it back in time.
  • FX1–FX4 shape it per step, and Fill writes ramps.
  • With the cursor on a TA step, SamplePlay opens this screen.

Master → Tape FX: the effects are sends

Grain, Ripple and Echo are send effects, one set per tape, set up in Master the way Reverb and Delay are. Spec §4.

fMasterParams.cpp · Master pressed until Tape FX
  • Instruments send in with Tape A send and Tape B send in Params → More, beside Reverb and Delay send. A tape sends to its own FX at 100 by default.
  • Grain, Ripple and Echo each open a sub-page with Back on 8, the way Master's Reverb and Delay buttons open theirs. Level is the return.
  • Inside a tape's FX the three run in series. There's no insert or send switch per block: the dry sound always stays on its track.
  • Colour isn't a separate block: Overdrive and Bit depth already exist on every instrument.

Grain sub-page

Vertical bars like every Tracker parameter page. Wet is on button 1 and selected when the page opens: one press, one turn. Spec §4.

Master → Tape FX → A Grain
  • More: Position · Warp · Feedback · Freeze · Route · Back.
  • Ripple: Wet · Mode · Pitch · Decay · Tone · Chord · Pluck · More. Its Pluck setting (own notes, or + sends) lets a kick that sends here strike the strings.
  • Echo: Level · Time · Sync · Feedback · Tone · Spread · Age · More.

Automation, with a Follow type

Params pressed again. It's the existing page: Destination, Type, values, Amount. Spec §6.

gInstrEdit.cpp · envelopesLabels · envStateLabels
  • New destinations on a tape: Speed, Grain Wet, Size, Position and Pitch, Ripple Wet, Pitch and Decay, Echo Time and Feedback.
  • New type Follow: an envelope follower on another track or the input. Here the kick on track 3 pulls Grain Size down.
  • Envelope, LFO (Random included), WT Env and WT LFO work on the new destinations unchanged.

Tape A and Tape B sends on any instrument

A drum instrument on track 3, in Params → More. Spec §1, §8, §9.

beside Reverb send and Delay send
  • This is how drums, samples and synths flow into the effects. The synth part settings get the same two sends.
  • The step FX Tape A send and Tape B send set them per step on any track, the way the Reverb send FX does now.

Sample Recorder, recording onto Tape A

The recorder you know, with a Target. It records while the song plays, waits for the bar line, and loops the take in time. Spec §7.

gSampleRec.cpp · Source · Level · Gain · … · Record
  • Source adds Tracks (resample the ordinary tracks), Track n, and Grain A/B, which freezes the grain buffer to tape.
  • Bar takes skip the trim step; Undo restores the tape. Free takes go through the usual trim and Save.
  • Bounce is Render Selection with a new destination, Tape A or Tape B.
  • From the pattern: the step FX Tape Rec (1–16 bars, 0 stops) starts a take on its step, using the Source and Dub set here. It only records while the tape track is armed (Shift + Rec, the arm row the pattern editor already has), so a song plays back without recording over the tapes.

theseus in the synth screens

theseus is a synth, so it's a Model in a synth part, edited like every other engine. Spec §8.

SynthEditor.cpp · Model · Polyphony · … · Load · Edit
  • Theseus joins the Model list. The note picks the drum, the pads are the kit, and step velocity is the hit's velocity.
  • In tape projects, pressing Reverb send again steps it to Tape A send, and Delay send to Tape B send. Here the drum part sends 64 into Tape A's FX.
SynthPatchEditor.cpp · Edit
  • The patch editor as it is: the engine's sections as a grid of icons on the left, the selected section's parameters on the right, Save, Save As, Init, Parameter and Back along the bottom.
  • theseus declares seven sections: Kit (Decay, Punch, Cutoff, FM, Noise, Tune), Hit LFO (LFO, Rate), and one per drum, Kick, Tom, Snare, Hats, Metal, each with Tune, Decay, Tone and Level.
  • Hitting a pad selects that drum's section in the grid. Here a snare hit has Snare selected.
  • Notes between two drum types blend their settings, so there are no steps at the edges.

Original Tracker: it has no synth parts today. The plan is one synth part for built-in engines only, with these same screens, if it fits in the spare flash and RAM. If it doesn't, theseus becomes a drum instrument whose screens copy this layout button for button.

Performance mode

Unchanged, with five tape FX added to its list. Spec §9.

fPerformance.cpp
  • New: Speed, Grain Freeze, Grain Wet, Ripple Wet, Echo Throw. The existing FX work on tape tracks as on any track.

Mini: ±10, +1, −1 and −10 play rows 1–4, as now.
