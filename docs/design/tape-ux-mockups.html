Tape Project Screens

These are the screens a tape project adds or changes, drawn at the Tracker's size and in its visual language: black ground, grey screen-button labels along the bottom, the red selection frame and the pattern colours. The two new colours are orange for lanes and pink for modulation. Each screen has notes on its controls and what's different on the Mini. The written spec is docs/design/tape-ux.md; section numbers below point into it.

Making a tape project

File → New Project, after the stop and save prompts that exist today. Spec §3.

fProjEdit.cpp · createNewProject()

Laid out like the Export choices: a page of screen-button options with a picture above them. The picture shows what the selected type gives you: reels for the tape tracks, plain columns for the ordinary ones.

  • Default is selected when the page opens, so Create makes today's project in one extra press.
  • A project's type can't be changed after it's made. Save As into a new tape project is the safe way across.

Mini: ±1 moves between the four types; button 8 creates.

The pattern editor, with lanes on Tape A

Tape 4. Tape A shows lane bank A in place of its two FX columns; Tape B still shows its FX columns. Spec §4.

fPatternEdit.cpp · patternViewMode

A lane is an FX column whose FX type is fixed for the whole pattern. Entering values works the way FX values do now: encoder, pads, Delete, Copy and Fill.

Fx again
Steps FX → A → B → C → D → FX. Four 2-character lanes take exactly the width of the two FX columns.
Hold Fx
The lane-target list on the right. Buttons 5–7 set the mode: Step, Hold or Glide.
Title bar
The lane under the cursor, in real units: A2 Rpt 1/16 Step.
Dim digits
Values still in force from an earlier step: Hold repeats them, Glide shows the in-between values.
→A
The header of an ordinary track that sends into Tape A's chain.

Mini: ±1/±10 set a value, Middle writes the last value, and the Fx button does the same as above.

Tape screen · Tape page

Params on a tape track, or Shift+Params from anywhere. Spec §5.

new module · core/interface/tapeMode/

The picture is the tape: the loop window lit, the rest dimmed, 16 slice ticks, the play head, and a bar ruler. The line above it says what feeds this track's chain.

  • L under Speed and Rpt: a lane in this pattern moves them.
  • Shift held on Start or Length zooms the waveform around that edge and switches the encoder to fine steps.
  • Params pressed again goes on to the instrument editor, then automation, then back here.

Mini: Menu → Tape. Shift+Left/Right changes the page.

Tape screen · Grain page

Wet is on button 1 and selected when you arrive: open the page, turn the encoder, and the grains are in. Spec §5.3.

GRAIN · 3 pages · dots in the title bar

The live buffer runs as a timeline of the last bars. Each grain is a mark that lights while it sounds, under the read cursor, with the count in words.

  • ~ and the pink rail under Size: M1 moves it. The rail spans its reach, and the dot shows where it is now.
  • Top-row pad 11 freezes while held; with Shift it latches, and FROZEN shows in the picture.

Holding M1 to give Size a depth

Bryo's "hold a modulator, turn a knob", on the Tracker's controls. Spec §6.2.

top-row pad 7 held · encoder

While pad 7 is held, the labels turn into M1's depths, signed and in pink. The picture plots M1's wave against the selected value's resulting motion.

  • A depth turned back to 0 catches there until the encoder rests for a quarter second.
  • Let go of the pad and the page goes back to values, with the rail left under Size.

Mini, or anyone: Mod page → M1 → Assign. The same pink labels appear, with an ASSIGN M1 badge; set depths with ±1/±10, then press Done.

Tape screen · Ripple page

The strings ring on the chord; notes on the track, and HIT sends from ordinary tracks, pluck them. Spec §5.3, §8.

RIPPLE · 2 pages

Four strings, each with its note, drawn moving while they ring. The chord name and the pluck source sit underneath.

  • Page 2: Cutoff · Resonance · Drive · Pluck · Keys · Route.

Tape screen · Mod page

Four slots, each with a live plot of its engine. Spec §6.1.

M1–M4 · Assign · Depths
  • Press a slot's button again for its own page, with Engine first: LFO, ADSR, Follow or SEQ.
  • Depths lists the slot's targets and amounts; Delete removes one.
  • The slots start as M1 a slow LFO, M2 an envelope, M3 a random LFO and M4 a SEQ.

Tape Recorder, armed

SampleRec on a tape track. The take waits for the bar line and blinks the way a queued pattern does. Spec §7.

Source · Bars · Dub · Gain · Arm · Bounce · Freeze → tape
  • Source defaults to the ordinary tracks, so what you wrote gets printed.
  • Dub at 0 adds the new sound to the old; +100 keeps the old loop and −100 replaces it.
  • Page 2: Tape length · Undo take · Clear tape (asks first, on buttons 7/8) · Sampler (the ordinary recorder).

Master · Tape Sends

A fourth Master mode, shown only in tape projects. This one is Tape 6, with four ordinary tracks. Spec §8.

fMasterParams.cpp · press cycles modes
  • Press a track's button for its send to A, and press again for B.
  • Shift + a track's button toggles HIT: that track's notes pluck the chain's strings and restart its envelopes.
  • Sends are taken before the fader, so a track turned all the way down is heard only through the effects.

A drum instrument (theseus)

Params on a drum instrument: eight values for eight buttons, so the kit fits one page. It works on every device. Spec §9.

playModeDrum · from operators-xy

The note picks the drum. The picture is the zone strip across the 48 pads, with Tune shifting it, and the hit LFO's steps under it.

  • The step's volume column is the hit's velocity.
  • Make one in the Sample Loader: an empty slot → New Drum.

Mini: the zones are labelled on the mini keyboard's keys.

Scenes

Perform pressed a second time: the press that switched between tracks 1–8 and 9–16, which a tape project doesn't need. Spec §11.

4 scenes · glide · Scene step FX
press
Recall, with the Glide time.
Shift + press
Store. Overwriting a stored scene asks on 7/8.
Delete + press
Clear, after a confirm.

The boxes say what each scene changes, in words, not only in fill: filled for the current scene, framed for a stored one, dotted for an empty one.

Performance mode with the tape FX

The same 12 slots and 4 stored values per slot. Tape projects add stutter, tape speed, freeze, wets, a dub throw and scene. Spec §12.

fPerformance.cpp · pad = slot × row
  • Tape FX act on the tape tracks selected on the bottom buttons; Tape A is selected here.
  • The Scene slot plays a scene while its pad is held and goes back to the previous scene on release.

Mini: ±10, +1, −1 and −10 play rows 1–4.

Pads on the Tape screen

Original and Tracker+. The bottom three rows play the track: slices with the deck as the instrument, notes otherwise. The top row is the deck's controls. Spec §5.2.
